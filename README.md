### Mert Coşkuner

MSc student in Computer Science & Engineering at **Sabancı University** and researcher at
**TÜBİTAK BİLGEM**. I work on trustworthy and efficient machine learning: Byzantine-robust
and private federated learning, backdoors in graph neural networks, adversarial
robustness and distillation, and low-bit quantization of multilingual language models.

[Website](https://mertcoskuner.github.io) · [LinkedIn](https://www.linkedin.com/in/mertcoskuner/) · [Email](mailto:mertcoskuner@gmail.com)

#### Selected work

| Project | Focus |
|---|---|
| [structure-aware-fedala](https://github.com/mertcoskuner/structure-aware-fedala) | Personalised federated graph learning with topology-weighted aggregation and degree-calibrated differential privacy |
| [tr-quantbench](https://github.com/mertcoskuner/tr-quantbench) | How calibration language shapes 4-bit GPTQ/AWQ quantization of multilingual LLMs, with a Turkish focus |
| [gnn-backdoor-attacks](https://github.com/mertcoskuner/gnn-backdoor-attacks) | GNNs for graph, node and link tasks with Graph Trojaning backdoors on graph classification |
| [cnn-robustness-cifar10](https://github.com/mertcoskuner/cnn-robustness-cifar10) | Corruption and adversarial robustness of transfer-learned and distilled CNNs |
| [transformer-feedback-channel-coding](https://github.com/mertcoskuner/transformer-feedback-channel-coding) | Transformer channel codes for the AWGN channel with feedback, learned end to end |
| [aspect-based-recommender](https://github.com/mertcoskuner/aspect-based-recommender) | Recommendation from reviews with instruction-tuned aspect-based sentiment analysis |
